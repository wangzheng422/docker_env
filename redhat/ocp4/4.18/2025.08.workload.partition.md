# workload partition

workload partition is a feature of openshift, which will isolate cpu core between openshift system component, and customer workload. These solution is very ideal for single node ocp or 3node compate ocp cluster, which openshift system component and customer workload running on same host, and competing for cpu core.

Here we weill demo what workload partition looks like, and run demo pod and demo vm, to see how it isolcate workload.

offical document is here:
- https://docs.redhat.com/en/documentation/openshift_container_platform/4.18/html/scalability_and_performance/enabling-workload-partitioning

Here is the dia of our demo:


# workload partition settings

To enalbe workload partition, you must enable is during ocp cluster installation pharse, by add this setting
```yaml
cpuPartitioningMode: AllNodes
```

After the openshift cluster installed, apply the performance profile setting, here is an example, we have 3node compact cluster, each node has 24 cpu core, for demo purpose, we reserve 20 cpu core to ocp system components, and only left 4 cpu core for workload.

```bash
tee $BASE_DIR/data/install/performance-profile.yaml << 'EOF'
```

## BestEffort pod

First, let us try best effort pod type.

```bash

tee $BASE_DIR/data/install/pod.yaml << 'EOF'
---
apiVersion: apps/v1
kind: Deployment
metadata:
  name: cpu-stress-deployment
  namespace: demo
spec:
  replicas: 1
  selector:
    matchLabels:
      app: cpu-stress
  template:
    metadata:
      labels:
        app: cpu-stress
    spec:
      # 关键修正1: 定义一个volumes块
      volumes:
        - name: temp-space # 为卷起个名字
          emptyDir: {}    # 类型是emptyDir
          
      containers:
        - name: stress-ng-container
          image: quay.io/wangzheng422/qimgs:rocky9-test-2025.04.30.v01
          
          # 关键修正2: 将上面定义的卷挂载到容器内部
          volumeMounts:
            - name: temp-space
              mountPath: "/tmp/stress-workdir" # 容器内的可写路径
              
          # resources:
          #   requests:
          #     cpu: "3"
          #     memory: "512Mi"
          #   limits:
          #     cpu: "3"
          #     memory: "512Mi"
```
