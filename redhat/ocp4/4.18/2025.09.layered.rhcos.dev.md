# using layered rhcos to add rsyslog package

you can customize rhcos, adding package by using layered rhcos.

- https://docs.redhat.com/en/documentation/openshift_container_platform/4.18/html/machine_configuration/mco-coreos-layering#mco-coreos-layering

you should run the testing on a rhel host to compile a rhcos image.

```bash

# first, get the rhcos image version.
oc adm release info --image-for rhel-coreos
# quay.io/openshift-release-dev/ocp-v4.0-art-dev@sha256:cbe2965ad3a408286fe06e4a7a58e006621f33847c17f8e8ff84504dbeebe666

```

on rhel host, we build the customized rhcos image, we install rsyslog package, with supported packages, and we also need plymouth, which will help to write to `boot.log` file.

```bash

mkdir -p /data
cd /data

dnf download --resolve --destdir=. rsyslog libestr libfastjson logrotate plymouth plymouth-core-libs plymouth-scripts


tee remote.conf << 'EOF'
# --- New exclusion rules ---
# If the log's process name is 'crio' or 'kubenswrapper', then stop processing and do not write to any file.
if $programname == 'crio' or $programname == 'kubenswrapper' then {
    stop
}
# --- End of exclusion rules ---
EOF

tee rhcos.dockerfile << EOF
FROM quay.io/openshift-release-dev/ocp-v4.0-art-dev@sha256:cbe2965ad3a408286fe06e4a7a58e006621f33847c17f8e8ff84504dbeebe666

COPY *.rpm /root/

RUN cd /root && dnf install --nobest -y rsyslog-*.x86_64.rpm logrotate-*.x86_64.rpm libestr-*.x86_64.rpm libfastjson-*.x86_64.rpm plymouth-*.x86_64.rpm && \
    ostree container commit

RUN rm -f /root/*.rpm

# Copy your custom configuration in
ADD remote.conf /etc/rsyslog.d/remote.conf

EOF

podman build --authfile /data/pull-secret.json -t quay.io/wangzheng422/qimgs:rhcos-4.18-rsyslog-2025.09.03-v03 -f rhcos.dockerfile .

podman push quay.io/wangzheng422/qimgs:rhcos-4.18-rsyslog-2025.09.03-v03

```

apply a new machine config, with the layered rhcos image, and a configue to create working path for rsyslog.

```bash

tee $BASE_DIR/data/install/machine-config.yaml << 'EOF'
---
apiVersion: machineconfiguration.openshift.io/v1
kind: MachineConfig
metadata:
  labels:
    machineconfiguration.openshift.io/role: master 
  name: os-layer-custom-master
spec:
  config:
    ignition:
      version: 3.2.0
    storage:
      files:
        # 关键部分：定义要在节点上创建的文件
        - path: /etc/tmpfiles.d/rsyslog.conf
          mode: 0644
          overwrite: true
          contents:
            # 文件内容是Base64编码的
            # 原始文本是: d /var/lib/rsyslog 0755 root root -
            source: "data:text/plain;charset=utf-8;base64,ZCAvdmFyL2xpYi9yc3lzbG9nIDA3NTUgcm9vdCByb290IC0K"
  osImageURL: quay.io/wangzheng422/qimgs:rhcos-4.18-rsyslog-2025.09.03-v02
EOF

oc apply -f $BASE_DIR/data/install/machine-config.yaml

```
