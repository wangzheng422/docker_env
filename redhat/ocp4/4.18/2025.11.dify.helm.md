# deploy dify on openshift 4.18

the upstream dify, does not support install on openshift, it runs with docker compose. there are some project like https://github.com/BorisPolonsky/dify-helm, will deploy dify on k8s, but it lack some priviledges settings, so it can not runs on openshift 4.18. Now we fix the problem

first, download the dify helm chart

```bash
wget https://github.com/BorisPolonsky/dify-helm/releases/download/dify-0.31.0/dify-0.31.0.tgz
```

then install the helm chart

```bash
helm install wzh-dify /<path to>/dify-0.31.0.tgz \
--create-namespace -n dify \
--wait 
```

give priviledge to service account

```bash
oc adm policy add-scc-to-user privileged -z default -n dify
oc adm policy add-scc-to-user privileged -z wzh-dify-redis -n dify
```

apply patch to all deployment

```bash
# Get the names of all deployments in the current namespace
DEPLOYMENTS=$(kubectl get deployment -n dify -o jsonpath='{.items[*].metadata.name}')

# Loop through and patch each deployment
for DEP in $DEPLOYMENTS; do
  echo "Patching deployment '$DEP'..."
  kubectl patch deployment $DEP -n dify --type='json' -p='[{"op": "add", "path": "/spec/template/spec/securityContext", "value": {"runAsUser": 0, "fsGroup": 0}},{"op": "add", "path": "/spec/template/spec/securityContext/seLinuxOptions", "value": { "level": "s0:c12,c28" }}]'
done
```

Then, you will get a working dify instance running on openshift 4.
