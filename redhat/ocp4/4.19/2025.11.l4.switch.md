# Using L4 Switch as Ingress Gateway for OpenShift

## Executive Summary

Standard OpenShift Router deployments typically recommend using a Layer 7 (L7) Load Balancer in front of the router pods to effectively distribute traffic. This configuration allows the Load Balancer to perform application-level health checks (e.g., `HTTP GET /healthz/ready`), ensuring traffic is only sent to fully operational instances.

However, in some infrastructure environments, only Layer 4 (L4) switches are available. L4 switches generally operate at the Transport Layer, performing health checks via simple TCP connection attempts (TCP alive check). This limitation creates a critical race condition during Router Pod migration or restarts:
1.  A new Router Pod starts, and its operating system opens the TCP ports.
2.  The L4 switch detects the open TCP port and immediately adds the pod to the active backend pool.
3.  However, the underlying HAProxy service within the pod may not yet be fully initialized or ready to handle HTTP requests.
4.  Consequently, traffic is routed to an unready pod, causing service disruption (503 errors or connection resets).

To address this challenge without requiring L7 infrastructure upgrades, we propose a **"Sidecar Health Check Translator"** solution. This mechanism runs a lightweight daemon alongside the router that proxies the router's L7 status to an L4-compatible TCP port.

## Architecture & Solution Design

The solution involves deploying a DaemonSet that runs as a "sibling" to the Router Pod on the same host. This daemon performs the following logic:
1.  **Monitor:** It continuously polls the local Router Pod's L7 health check endpoint (`http://localhost:1936/healthz/ready`).
2.  **Translate:**
    *   If the Router is **Healthy** (L7), the daemon opens a specific TCP port (e.g., 18898) on the host.
    *   If the Router is **Unhealthy** (L7) or the check fails, the daemon **immediately** closes the TCP port.
3.  **Route:** The external L4 switch is configured to check this "Translator Port" (18898) instead of the direct router port. Traffic is only sent to nodes where the Translator Port is open, ensuring the underlying Router is truly ready.

```mermaid
sequenceDiagram
    participant LB as External L4 Load Balancer
    participant Agent as Health Check Translator<br/>Sidecar DaemonSet
    participant Router as OpenShift Router<br/>HAProxy

    Note over Agent, Router: Continuous Loop Monitoring
    Agent->>Router: HTTP GET /healthz/ready
    alt Router is Healthy 200 OK
        Router-->>Agent: 200 OK
        Agent->>Agent: Open TCP Port 18898
    else Router is Unhealthy
        Router-->>Agent: Error or Timeout
        Agent->>Agent: Close TCP Port 18898
    end

    Note over LB, Agent: L4 Health Check Process
    LB->>Agent: TCP SYN to Port 18898
    alt Port Open
        Agent-->>LB: TCP SYN-ACK
        LB->>LB: Mark Backend UP
        LB->>Router: Forward User Traffic Port 80 443
    else Port Closed
        Agent-->>LB: TCP RST or No Response
        LB->>LB: Mark Backend DOWN
        LB->>LB: Stop Routing Traffic
    end
```

## Simulation and Verification

We will demonstrate this solution by simulating the environment using a local HAProxy instance. The verification process consists of three phases:
1.  **Baseline:** Testing with L7 health checks (Ideal Scenario).
2.  **Problem Reproduction:** Testing with standard L4 checks (Showing failure).
3.  **Solution Verification:** Testing with the L4 Health Check Translator (Showing success).

### Phase 1: Run with L7 Switch (Baseline)

First, we install HAProxy locally to simulate an external Load Balancer.

```bash
dnf install -y haproxy
```

Configure HAProxy as an L7 switch. This configuration directly checks the router's HTTP health endpoint.

```bash
setsebool -P haproxy_connect_any 1

tee /etc/haproxy/haproxy.cfg << EOF
global
  log stdout format raw local0
  maxconn 20000

defaults
  log     global
  mode    http
  option  httplog
  option  dontlognull
  # option  forwardfor
  timeout connect 1000
  timeout client  50000
  timeout server  50000

frontend http_front
  bind *:8080
  stats uri /haproxy?stats
  # 明确设置 X-Forwarded-For 为原始客户端 IP
  # http-request set-header X-Forwarded-For %[src]
  # 明确设置 X-Forwarded-Proto 为 http，因为我们的前端是 http
  # http-request set-header X-Forwarded-Proto http
  default_backend http_back

backend http_back
  balance roundrobin
  # --- L7 Health Check ---
  option httpchk GET /healthz/ready HTTP/1.0
  http-check expect status 200
  # Set default health check interval to 2 seconds (2000ms) for all servers
  default-server inter 2000
  # -----------------------
  # --- 最终修正：应用流量发到 80，健康检查发到 1936 ---
  server pod-1 192.168.99.23:80 check port 1936
  server pod-2 192.168.99.24:80 check port 1936
  server pod-3 192.168.99.25:80 check port 1936
EOF


systemctl restart haproxy

```

### Phase 3: Run with L4 Check Translator (Solution Verification)

To mitigate this, we implement the Health Check Translator.

First, we create a ConfigMap containing the Python script. This script acts as the logic engine, checking the router's status and toggling the listening port.

```yaml
apiVersion: v1
kind: ConfigMap
metadata:
  name: health-check-script
  namespace: l4-switch-demo
data:
  check.py: |
    import http.server
    import socketserver
    import threading
    import time
    import requests
    import os
    import signal
    import sys

    # --- Configuration ---
    ROUTER_HEALTH_URL = "http://localhost:1936/healthz/ready"
    HEALTH_CHECK_INTERVAL = 1  # seconds
    LISTENING_PORT = 18898
    LISTENING_IP = "0.0.0.0"

    # --- Global State ---
    server_process = None
    is_healthy = False

    def start_listener():
        """Starts a simple HTTP server in a separate process."""
        pid = os.fork()
        if pid == 0:
            # This is the child process
            try:
                handler = http.server.SimpleHTTPRequestHandler
                with socketserver.TCPServer((LISTENING_IP, LISTENING_PORT), handler) as httpd:
                    print(f"Child process serving on port {LISTENING_PORT}")
                    httpd.serve_forever()
            except Exception as e:
                print(f"Child process failed: {e}")
            finally:
                # Ensure the child process exits cleanly if server stops
                os._exit(0)
        else:
            # This is the parent process
            print(f"Parent process started listener child with PID: {pid}")
            return pid

    def stop_listener(pid):
        """Stops the listener process immediately."""
        if pid:
            print(f"Stopping listener process with PID: {pid}")
            try:
                os.kill(pid, signal.SIGKILL)
                os.waitpid(pid, 0)
                print(f"Listener process {pid} killed.")
            except ProcessLookupError:
                print(f"Listener process {pid} not found, already stopped?")
            except Exception as e:
                print(f"Error killing listener process {pid}: {e}")
        return None

    def check_router_health():
        """Checks the L7 health of the local router pod."""
        try:
            response = requests.get(ROUTER_HEALTH_URL, timeout=0.5)
            if response.status_code == 200:
                return True
            else:
                print(f"Router health check failed with status code: {response.status_code}")
                return False
        except requests.exceptions.RequestException as e:
            print(f"Router health check failed with exception: {e}")
            return False

    def main_loop():
        global server_process
        global is_healthy

        while True:
            current_health = check_router_health()

            if current_health and not is_healthy:
                print("Router is healthy. Starting listener.")
                is_healthy = True
                if server_process:
                    server_process = stop_listener(server_process)
                server_process = start_listener()

            elif not current_health and is_healthy:
                print("Router is unhealthy. Stopping listener immediately.")
                is_healthy = False
                if server_process:
                    server_process = stop_listener(server_process)
            
            time.sleep(HEALTH_CHECK_INTERVAL)

    if __name__ == "__main__":
        print("Starting router health checker...")
        # Graceful shutdown handler
        def signal_handler(sig, frame):
            print("Shutdown signal received. Stopping listener...")
            if server_process:
                stop_listener(server_process)
            sys.exit(0)

        signal.signal(signal.SIGINT, signal_handler)
        signal.signal(signal.SIGTERM, signal_handler)

        main_loop()
```

Deploy the DaemonSet to run this script on every node. We use `hostNetwork: true` so the script can access the router's localhost port and expose the translator port to the external network.


## Support and Recommendations

The method described here acts as a **Reference Architecture / Proof of Concept (PoC)** for enabling L4 switches in OpenShift environments. While functional, it is a DIY solution.

For enterprise-grade implementations, we recommend consulting **Red Hat Global Professional Services (GPS)** for a tailored solution. Potential enhancements for production use include:
1.  **Performance Optimization:** Rewrite the Python translator in **Golang** to reduce resource footprint (CPU/Memory) and improve reaction speed.
2.  **Security Hardening:** Implement `iptables` or `nftables` rules on the node to ensure the translator port (18898) accepts connections *only* from the trusted L4 switches, preventing unauthorized access.
3.  **Error Handling:** Add more robust logging and error handling for edge cases (e.g., API server downtime, network partitions).
