# DGX Spark Qwen3.6 NVFP4 Report Package - English

This directory is a standalone English translation of the final r6 report. Copy the whole directory to preserve local image links.

## Files

- `spark-qwen3.6-nvfp4-inference-report-2026.06.01-r6-en.md`: English Markdown report with image links pointing to `images/`.
- `spark-qwen3.6-nvfp4-inference-report-2026.06.01-r6-en.html`: English HTML export generated from the standalone Markdown.
- `images/`: all SVG images referenced by the report.
- `data/`: compact CSV files used for the r6 charts and added tables.
- `image-manifest.csv`: mapping from the original report image paths to standalone package paths.

The English report preserves model names, runtime names, benchmark values, and chart assets from the Chinese r6 report.
