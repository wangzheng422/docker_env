# DGX Spark Qwen3.6 NVFP4 Report Package

This directory is a standalone copy of the final r6 report. Copy the whole directory to preserve local image links.

## Files

- `spark-qwen3.6-nvfp4-inference-report-2026.06.01-r6.md`: Markdown report with image links rewritten to `images/`.
- `spark-qwen3.6-nvfp4-inference-report-2026.06.01-r6.html`: HTML export generated from the standalone Markdown.
- `images/`: all SVG images referenced by the report.
- `data/`: compact CSV files used for the r6 charts and added tables.
- `image-manifest.csv`: mapping from original report image paths to standalone package paths.
